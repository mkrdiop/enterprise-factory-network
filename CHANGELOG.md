# Changelog

All notable repository and EFS contract changes are recorded here. Entries describe merged changes; they do not by themselves constitute an immutable release or a published artifact.

The following structure is a proposed repository convention:

- Group entries by date or future release identifier.
- Use the categories Added, Changed, Fixed, Deprecated, Removed and Security where relevant.
- Link each entry to its pull request and Linear issue when available.
- Do not invent release numbers or imply that a Git merge is an artifact-registry publication.
